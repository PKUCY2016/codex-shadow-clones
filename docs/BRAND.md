# Visual identity

The project mark depicts three ninja clones in mint, cyan and violet. `assets/logo.svg` is the editable vector mark; `assets/icon.png` and `assets/AppIcon.icns` are native macOS assets rendered by `scripts/render_icon.swift`. The menu bar uses a monochrome three-ninja drawing.

`assets/poster.png` was generated with the built-in image generation tool for this project. It shows a stylized coding-terminal emblem, not a claim of official OpenAI affiliation. The project logo is independent artwork.

Poster direction: landscape technology launch poster; midnight navy, electric mint/cyan; title “CODEX SHADOW CLONES”; subtitle “One workspace. Many ninjas.”; three hooded ninja mascots in front of a glowing Codex terminal emblem; feature labels Independent accounts, Shared projects, History snapshots, Quota monitor; community project, macOS, open source.
